## 0. 지금 상황

사용자 플레이 평가("재미없고 복잡하고 허접하다")로 **게임 정리**를 시작했다. 규칙을 캐슬버스터즈처럼 단순하게 되돌린다.
- **승리:** 해적 전멸 또는 선장실 파괴. 24턴 뒤에는 남은 해적 체력 비율로 가린다.
- **한 턴:** 바다 전체를 연료만큼 이동하고, 해적 한 명이 한 발을 쏜다.
- **판마다 달라지는 것:** 배 짓기, 바람, 파도 구간.

기준 문서(설계서 2~6장, BALANCE A부)는 새 규칙으로 다시 썼고, 엔진·AI·데이터·앱이 새 규칙으로 돈다(ADR-112~115). 화면 정리(S3)·해역 1 12판(S6)까지 끝났고, 사용자 확인(S2·S4)과 손맛 점검(S5)이 남았다.

- **밸런스 (ADR-115, 피해 1.5배):** sim_runner 1,000판 — 보통 평균 16.5턴·턴 제한 13.1%·전멸 44.5%·선장실 42.4%, 어려움 14.2턴·3.6%. B2 목표 모두 맞춤.
- **실기기:** `R3CX90JQLEB` 에 최신 main(프로필 빌드) 설치. APK `D:/Projects/pb-playtest/app-profile.apk`. 옛 저장 설계도로 회색 화면이 나던 문제는 고쳤다(`legacy_save_test`).
- **이번 정리에서 한 일 (모두 main):** S1 규칙 잘라내기, S1 사후 점검·결정 반영(동시 무승부·흔들기·둘레 비율·등급 배율, ADR-113), S2 바다·바람·이동, S3 앱 정리, S4 타격감(CC0 폭발·실녹음·새 곡), S6 해역 1 1-6~1-11, 효과 골든 5판, 앱 사후 점검·남은 일, ARB 문구 검수(용어표 `docs/plans/2026-10-13-arb-glossary.md`), 안 쓰는 에셋 113개 정리와 가져오기 제외 목록, sim_runner 기본 jobs 8, 옛 저장 핫픽스.

## 2. 정리로 대체된 것
