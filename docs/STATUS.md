## 3. 다음에 할 일 (권장 순서)

1. **사람 확인 몫 정리:** A24·A44·A45·A48·A50 실기기 확인(코드는 main 에 있음).
2. **MVP 종료 게이트 (사용자 몫 포함):** 실기기 2대 해시, release 빌드 설치, 두 언어 화면, 해역 1 완주, 저사양 프레임, 손맛 확인.
3. **남은 A 단계 중 비공개 테스트 전에 끝낼 것:** A33·A35~A37 (전투 화면 품질). A35·A36 은 설계서 문장(바람 줄·돛 펄럭임, 단계 안 그을음 농도)이 먼저 필요하다.
4. **비공개 테스트** (12명 × 14일) → 피드백 반영.
5. **정식 출시 R2 → R3 → R4 → R5 → R6**, 그 사이 A1·A2·A3·A4. R4 가 기댈 수치(특성·상자·랭크·상점)는 ADR-103 으로 정했다(임시값).
