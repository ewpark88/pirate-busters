## M3 — 이동·연료·파도·침수·시간 판정 `pb_sim` (2026-09-29, 브랜치 `feat/M3-motion-flood`)

**완료**
- 넓은 전장(시작 간격 28칸, 이동 ±10칸, 월드 ±100칸)과 사거리 등급 4개·탄속 정수 표 (§2.1, §2.6, §2.8)
- `MOVE(dx)`(1/10칸): 한계선·연료·남은 턴 시간 중 먼저 닿는 곳까지, 간 거리만큼 연료. 거리 ÷ 속도(× (1 − 침수량 × 0.6))만큼 턴 시계를 쓰고 그동안 온 커맨드는 이동 뒤에 처리 (§2.6, §2.7, ADR-025)
- 연료: 슬루프 탱크 80·1칸 4, 내 턴 시작 +30(상한까지) (§2.7)
- 파도: 정수 사인파 위아래·기울기, 주기 4초, 두 배 반주기 어긋남. 발사 순간의 흔들림이 발사 높이·각도에, 비행 중 표적의 흔들림이 충돌에 들어간다 (§2.5)
- 흘수선 = 무게 ÷ (폭 × 4), 새는 칸 = 구멍 단계 블록 + 부서진 칸, 자기 턴 끝 침수(+3%p / +1.5%p), 내려앉기, 침수 기울기 (§2.5, §3.4)
- 판정: 전멸 → 격침(내구도) → 격침(침수 100%), 30턴 뒤 시간 판정(침수량 차 1%p 초과 → 내구도 비율 → 무승부) (§2.4)
- 폭풍 타임(27~30턴): 파도 1.5배·바람 2배·침수 1.5배·턴 20초·후퇴 한계 6칸 당김(밖이면 한계선으로)·양쪽 연료 +30
- `runHeadless`(헤드리스 한 판 → 결과·해시·리플레이), 리플레이 v4
- 골든 리플레이 10판(`test/golden/*.json`, 재생성 `dart run test/golden/generate.dart`): 격침(내구도)·격침(침수)·전멸·시간 판정 승·무승부·항복 + 무작위 4판
- 완료 조건 근거: `골든 판들은 격침(내구도)·격침(침수)·전멸·시간 판정·무승부·항복을 모두 다룬다`, `time_decision_test.dart` 시간 판정 시나리오 10종, `같은 턴 묶음 목록(이동 포함)이면 연료·위치까지 최종 해시가 100번 모두 같다`

**결정**

- M2·M3: 기울기를 충돌·발사 위치에도(보이는 모습 = 판정), 같은 해적 한 턴 두 번 금지·쿨다운 0~2, 부서지는 연출 동안 타이머 정지, 한계선 앞 감속, 탄도 반 스텝 보정, 리플레이 v5·골든 재생성
- M4: 배 위 해적 끌어 조준·핀치·탭 제스처, 상대 조준 자세, 해적 자세(조준·낙하·헤엄·복귀·쓰러짐), 전투 외곽선 부위, 바다(해역 테마 맑은 낮·격자·포말 파티클·수면이 배를 따름), 한계선 암초·부표, 5초 카운트다운, 상대 턴 항복 예약, 미리 고른 해적 유지, 영어 복수형, 피해 숫자·격침 배너 l10n, HUD 골든(두 언어 × 두 크기, Windows 에서만 비교)
- 실기기(SM S921N, Android 16, Impeller Vulkan) 설치·실행 확인

**주의 (테스트)**
- 위젯 테스트에서 GameWidget 은 루프가 돌지 않는다. 전장은 `load → mount → update(0) → ready` 로 직접 띄워 그린다. 앞 테스트의 `rootBundle` 캐시 Future 가 다음 테스트에서 끝나지 않으므로 `rootBundle.clear()` 를 먼저 부른다. 캐릭터 부위는 게임의 `images` 로 읽는다(전역 `Flame.images` 금지)
