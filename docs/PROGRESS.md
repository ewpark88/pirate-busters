## M3 — 이동·연료·파도·침수·시간 판정 `pb_sim` (2026-09-29, 브랜치 `feat/M3-motion-flood`)

**완료**
- 넓은 전장(시작 간격 28칸, 이동 ±10칸, 월드 ±100칸)과 사거리 등급 4개·탄속 정수 표 (§2.1, §2.6, §2.8)
- `MOVE(dx)`(1/10칸): 한계선·연료·남은 턴 시간 중 먼저 닿는 곳까지, 간 거리만큼 연료. 거리 ÷ 속도(× (1 − 침수량 × 0.6))만큼 턴 시계를 쓰고 그동안 온 커맨드는 이동 뒤에 처리 (§2.6, §2.7, ADR-025)
- 연료: 슬루프 탱크 80·1칸 4, 내 턴 시작 +30(상한까지) (§2.7)
- 파도: 정수 사인파 위아래·기울기, 주기 4초, 두 배 반주기 어긋남. 발사 순간의 흔들림이 발사 높이·각도에, 비행 중 표적의 흔들림이 충돌에 들어간다 (§2.5)
- 흘수선 = 무게 ÷ (폭 × 4), 새는 칸 = 구멍 단계 블록 + 부서진 칸, 자기 턴 끝 침수(+3%p / +1.5%p), 내려앉기, 침수 기울기 (§2.5, §3.4)
- 판정: 전멸 → 격침(내구도) → 격침(침수 100%), 30턴 뒤 시간 판정(침수량 차 1%p 초과 → 내구도 비율 → 무승부) (§2.4)
- 폭풍 타임(27~30턴): 파도 1.5배·바람 2배·침수 1.5배·턴 20초·후퇴 한계 6칸 당김(밖이면 한계선으로)·양쪽 연료 +30
- `runHeadless`(헤드리스 한 판 → 결과·해시·리플레이), 리플레이 v4
- 골든 리플레이 10판(`test/golden/*.json`, 재생성 `dart run test/golden/generate.dart`): 격침(내구도)·격침(침수)·전멸·시간 판정 승·무승부·항복 + 무작위 4판
- 완료 조건 근거: `골든 판들은 격침(내구도)·격침(침수)·전멸·시간 판정·무승부·항복을 모두 다룬다`, `time_decision_test.dart` 시간 판정 시나리오 10종, `같은 턴 묶음 목록(이동 포함)이면 연료·위치까지 최종 해시가 100번 모두 같다`

**제안 2 — 11장 미정 사항 4건의 설계서 문구 (현재 구현 기준, 사용자 결정 뒤 설계서 반영)**
- 바다에 빠진 해적의 복귀(§2.3): 다음 내 턴 시작에 **같은 슬롯의 원래 선실 칸**으로 돌아온다. 선실 블록이 부서져 있으면 드러난 채라 직격에 맞고(ADR-010), 잠겨 있으면 쏠 수 없다. → §2.3 표 문구에 이 두 줄을 더하자는 제안
- 동시 격침·자기 피해(§2.4): 즉시 판정은 전멸 → 격침 → 침수 순으로 보고, 같은 조건을 양쪽이 채우면 무승부(승자 −1), 다른 조건이면 먼저 보는 조건의 패자가 진다(예: A 전멸 + B 격침 → B 승). 내 탄은 내 배에 닿지 않고(지원탄은 수리만), 자기 피해는 턴 끝 침수·상대가 건 턴 효과뿐이라 ‘내 유폭으로 내 격침’은 없다. → §2.4 에 순서 규칙과 ‘내 탄은 내 배에 닿지 않는다’ 를 적자는 제안. 대안: 다른 조건이어도 무승부
- 잠긴 선실(§2.5·§3.3): 건조 검사는 흘수선 아래 선실을 허용하고, 잠긴 선실의 해적은 쏠 수 없을 뿐 전멸로 치지 않으며, 모두 잠겨도 판은 격침·침수 100%·시간 판정으로만 끝난다. → §2.5 에 ‘모든 선실이 잠겨도 즉시 지지 않는다’ 를 적고, 흘수선 아래 선실은 허용(플레이어 책임)으로 §3.4 에 적자는 제안. 대안: 건조 검사에서 막기
- 탄 비행 중 커맨드(§7.2): 엔진은 FIRE 를 받으면 착탄까지 한 번에 계산하고 비행 틱만큼 턴 시계를 멈춘다. 비행 중 시각의 커맨드는 착탄 뒤로 밀려 처리되며 두 번째 FIRE·MOVE 는 막지 않는다(발사 수·쿨다운만 검사). 파도 위상은 정지 시간을 포함한 실제 시각. 앱은 연출 중 입력을 막고 분열탄 TAP 만 받는다. → §7.2 에 이 세 문장을 적자는 제안

- 해적을 바꾸면 더미배 손상이 처음으로 돌아간다(판 도중 선실 교체 규칙이 pb_sim 에 없음). 이어 가려면 설계서 규칙 변경이 필요하다
- 스토어 빌드에서도 스위치가 켜지고, 켠 채 편성하면 갖지 않은 해적이 캠페인 덱에 저장된다. 출시 전에 ADR-029·053 과 함께 뺄지 다시 본다
