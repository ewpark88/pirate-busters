# S5 준비: AI 이동 개선과 밸런스 제안 (2026-10-13)

계획서 0장 S5(한 판 손맛 점검) 전에 AI 이동을 고치고, B2 검증 목표(BALANCE.md B2: 턴 제한으로 끝나는 판 25% 이하, 평균 사용 턴 14~20)에 맞추려면 어떤 수치를 바꿔야 하는지 `sim_runner` 로 쟀다.
**BALANCE.md 는 고치지 않았다.** 아래 변경안은 사용자 승인이 필요하다.

해적별 승률(보통·지금 → 어려움·이동 목표): 스타리 59.0% → 56.6%, 히포 53.1% → 55.8%, 샤키 42.0% → 42.5%. 나머지는 46~52%. 모두 B2 상한 65% 안이지만 sim_runner 경고(같은 등급 평균 +5%p)는 스타리·히포가 넘는다.

**측정하지 못한 것:** 블록 피해 ×1.25, 턴 제한 28, 턴 28 + 블록 피해 ×1.25 는 두 번째 묶음을 돌리던 중 시스템 메모리 부족으로 멈춰 결과가 없다. 같은 명령(`--max-turns 28`, 블록 피해만 올린 `--data` 복사본)으로 다시 잴 수 있다.

### 읽은 것

- 명중률이 계열마다 92~99% 다. AI 가 못 맞혀서 판이 길어지는 것이 아니다. **한 판 24턴(각 12발) 안에 해적 체력 합을 다 깎기 어렵다**는 것이 턴 제한이 많은 이유다.
- 이동을 더 하게 해도(보통 간격 3칸: 1.28칸/턴) 턴 제한 비율은 그대로다. 해적 피해 ×1.25 도 거의 그대로다. 해적은 선실 블록 안에 있어 블록을 먼저 부숴야 하고, 피해가 올라도 맞는 발 수가 줄지 않는 구간이 많다.
- 턴 제한을 30 으로 늘리면 턴 제한 비율은 19.1% 로 목표 안에 든다. 평균 사용 턴은 22.7 로 B2 목표(14~20)를 넘는다. 다만 이 평균에는 턴 제한까지 간 판이 들어 있다.

## 3. BALANCE.md A부 변경안 (사용자 승인 필요)

| 항목 (BALANCE.md) | 지금 | 제안 | 근거 (측정) |
| --- | --- | --- | --- |
| A2.4 턴 제한 | 양쪽 합쳐 24턴(각 12) | **30턴(각 15)** | 보통 턴 제한 41.9% → 19.1%, 전멸 53% · 선장실 28% 로 둘 다 나온다 |
| B2 평균 사용 턴 목표 | 14~20 | **16~24** (턴 제한 30 에 맞춰) | 턴 30 에서 평균 22.7 |
| A5.5 이동 목표 (새 줄) | 없음 | 잔잔한 목표 쪽으로 1칸당 +15, 찾는 거리 12칸 (어려움 이상) | 어려움 턴 제한 23.4% → 19.9%, 선장실 승리 25.7% → 29.0% |
| A5.5 위치 후보 간격 | 1칸 | **그대로** | 3칸으로 넓혀도 턴 제한이 줄지 않았다(보통 42.6%, 어려움 23.6%) |
| A5.5 파도 구간 고려 (보통) | 안 함 | **그대로** | 켜도 턴 제한 44.2% 로 나아지지 않았다 |
| A4.3 해적 피해 | 계열 표 | **그대로** | ×1.25 로 올려도 보통 턴 제한 43.0% |

**함께 물을 것**

1. 턴 제한을 30 으로 늘리면 설계서 §2.7·§13.4(“남은 턴 수 24에서 감소”)와 CLAUDE.md 머리말도 함께 바뀐다. 다른 길(블록 내구도를 낮추기, 선실 둘레 블록 줄이기)은 아직 재지 못했다. 30턴으로 갈지, 블록 쪽 실험을 먼저 볼지 정해 주면 된다.
2. 어려움 AI 이동 목표 점수(+15/칸, 12칸)를 BALANCE A5.5 에 넣을지.
3. 스타리(59%)·히포(55.8%)가 같은 등급 평균보다 5%p 넘게 이긴다. B2 의 65% 안이라 S5 손맛 점검 뒤에 볼지.

## 4. 다시 재는 법

```bash
dart run tools/sim_runner/bin/sim_runner.dart --games 1000 --left normal                 # 지금
dart run tools/sim_runner/bin/sim_runner.dart --games 1000 --left normal --max-turns 30  # 턴 제한 실험
dart run tools/sim_runner/bin/sim_runner.dart --games 1000 --left hard --goal-moves 1    # 목표 후보 실험
```

수치 실험(피해·체력)은 `app/assets/game` 을 저장소 밖 임시 폴더로 복사해 고친 뒤 `--data <폴더>` 로 준다. 끝나면 임시 폴더는 지운다.
