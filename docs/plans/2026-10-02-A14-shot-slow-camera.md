# 탄 비행 1.3배 느리게 + 카메라가 탄을 따라감 (A14)


## Context
실기기에서 사용자가 지적한 두 가지다. ① 폭탄이 너무 빨리 날아간다. ② 쏜 순간부터 적 배에 맞을 때까지 카메라가 탄을 따라가야 한다.
- 비행 속도는 BALANCE.md A2.8 중력 16칸/초²(`packages/pb_sim/lib/src/world/world.dart:26` `gravityPerTick = 1778`)로 정해진다. 앱(`app/lib/battle/playback.dart:39`)은 시뮬 틱 그대로 실시간 재생하므로 앱만 고칠 일이 아니다.
- 카메라(`app/lib/game/camera_director.dart` `target()` 의 projectile 분기)는 설계서 §2.1 대로 "탄과 목표 배가 함께 보이게 줌아웃"한다. 그래서 화면이 처음부터 넓게 빠져 탄을 따라가는 느낌이 없다.

사용자 결정은 두 가지다. 탄 비행은 사거리를 유지한 채 중력·탄속을 함께 낮춰 1.3배 느리게 한다. 코드는 같은 전투 화면을 고치는 A13 세션에 넘기고, 이 세션은 기준 문서와 계획만 한다.

## 이 세션이 할 일 (문서)
1. **BALANCE.md A2.8 탄도 시간 (사용자 승인 1.3배):**
   - 중력: 16 → 9.5칸/초² (이전 16, ADR-069)
   - 등급별 최대 탄속 √(사거리×중력): 짧음 15.7 · 보통 18.5 · 긺 21.8 · 매우 긺 25.0
   - 최대 힘·45° 비행 시간: 짧음 2.3초 · 보통 2.8초 · 긺 3.2초 · 매우 긺 3.7초
   - 목표 줄: "긴 사거리 최대 힘 3.2초 안팎"
   - 바람 가속은 중력 비율(A2.3)이라 문구는 그대로다. B부에서 중력·비행 시간을 쓰는 표가 있으면 다시 계산한다.
2. **설계서 §2.1 카메라 문구:** "탄과 목표가 함께 보이도록 필요한 만큼만 줌아웃" 을 "탄을 화면 가운데 가까이 두고 거의 같은 줌으로 따라간다(높이 올라가면 해수면이 보일 만큼만 줌아웃). 탄이 적 배에 가까워지면 목표 배가 화면에 들어오고 착탄 지점에서 멈춘다" 로 바꾼다. 나머지(착탄·파괴 연출까지, 상대 턴 동일, 앞선 탄)는 그대로 둔다.
3. **계획서 12장 끝에 A14 추가 (절대 규칙 11, 끝난 A6 코드 재수정):**
   - A14 탄 비행 1.3배·카메라 탄 추적 — `pb_sim`, `pb_ai`(확인), `app`
     - [ ] `gravityPerTick` 을 A2.8 값으로, 사거리 등급 탄속 표 재계산(§2.8)
     - [ ] 테스트: 등급별 최대 힘·45° 비행 틱 수가 A2.8 표(±1틱). 골든 리플레이·해시 재생성
     - [ ] AI 조준 솔버·`sim_runner` 가 새 상수로 도는지 확인
     - [ ] 카메라(§2.1): 탄 중심 추적, 목표 배는 접근 때 들어옴, 착탄 지점 정지. `camera_director_test` 갱신
     - 완료 조건: 실기기에서 긴 사거리 최대 힘이 약 3.2초 날고, 카메라가 발사부터 착탄까지 탄을 화면 안 가운데 근처에 둔다. verify 통과.
   - 해시·날짜 갱신. `/adr` 로 ADR-069 를 남겼다(ADR-068 은 A13 세션이 씀).
4. `dart run tool/check_doc_sync.dart` 통과를 확인한다. 사용자가 요청하면 내 경로만 커밋한다(A13 세션과 공유 트리, 현재 브랜치 `feat/A13-battle-fx`).
5. A13 세션에 SendMessage 로 A14 착수를 넘긴다: 바뀐 A2.8 값, §2.1 문구, 대상 파일(`world.dart`, `camera_director.dart`, 비행 틱 테스트, 골든 해시), A13 과 같은 브랜치에서 할지 A13 머지 뒤 `feat/A14-…` 로 할지는 그쪽 상황에 맞춘다.
