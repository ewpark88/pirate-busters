# 해적 세트 효과 추가 — 설계서·계획서 수정 계획

## Context
사용자가 설계서 수정을 직접 요청했다: 같은 덱(출전 편성)에 특정 해적 조합이 있으면 공격·방어 보너스를 주는 **세트 효과**. 최대 7명 출전이므로 2세트·3세트 효과를 둔다. 세트마다 효과가 달라야 편성 전략이 생긴다.
결정(사용자 선택): **테마 세트 10개 × 4명, 해적 1명은 세트 1개에만 속함**, **전투 시작 때 출전 편성으로 판정하고 끝까지 고정**(§3.5 선체 보정과 같은 방식).
새 기능이므로 계획서에는 12장 끝에 `A3` 로 붙인다(절대 규칙 11, ADR-024). 코드는 건드리지 않는다(현재 단계 범위 밖).

## 1. 설계서 수정 (`Pirate Busters 게임 설계서.md`)

### 새 절 §4.7 세트 효과 (§4.6 뒤)
규칙:
- 세트 10개, 세트마다 해적 4명. 출전 해적 중 같은 세트 **2명 → 2세트 효과**, **3명 이상 → 3세트 효과(2세트 효과에 더함)**. 4명을 태워도 3세트와 같다.
- 7명이면 3+2+2 처럼 세트 3개까지 동시에 켤 수 있다. 코스트 한도(§4.5) 안에서 “세트를 맞출까, 강한 해적을 태울까”가 편성 고민이 된다.
- **전투 시작 때 출전 편성으로 한 번 판정**하고 전투 끝까지 유지한다. 해적이 쓰러져도 꺼지지 않는다.
- 세트 효과는 해적 레벨·등급과 무관한 고정 수치(‰ 정수). pb_data 가 매치 시작 때 계산해 pb_sim 에 넘긴다(§7.1). 레벨 보정 PvP(§4.4)에서도 그대로 적용.
- 각 세트에 일반 해적이 최소 1명 있어 초반에도 2세트를 맞출 수 있다(시작 해적 옥토=심연 교단, 톡=산호초 이웃; 해역 2 에서 샤키+본즈로 첫 2세트 ‘망령 선단’).
- 수치는 Remote Config `set_*`. 시즌 해적은 기존 세트의 5번째 멤버 또는 새 세트로 넣는다.

세트 표 (멤버 · 2세트 · 3세트):

| 세트 | 멤버 (등급) | 성격 | 2세트 | 3세트 (추가) |
|---|---|---|---|---|
| 집게 형제단 | 팡(일)·꽃게 형제(희)·킹(희)·랍(영) | 해적 사냥 | 해적 대상 피해 +10% | 적 해적을 쓰러뜨린 해적은 쿨다운 즉시 0 |
| 망령 선단 | 샤키(일)·본즈(희)·크래비(희)·데비(전) | 끈질김 | 우리 해적이 처음 쓰러질 때 체력 1로 버팀(전투당 1회) | 처음 쓰러진 해적 1명이 다음 내 턴 시작에 체력 30%로 부활(전투당 1회) |
| 하늘 편대 | 폴리(일)·윙(일)·펠리(희)·알바(영) | 공중 정밀 | 우리 발사체가 받는 바람 영향 −30% | 공중 계열 쿨다운 −1턴(최소 0) |
| 가시 동맹 | 스타리(일)·퍼피(일)·우니(영)·라이언(영) | 폭발 | 폭발 착탄 블록 피해 +15% | 폭발 착탄 반경 +1칸 |
| 고래 가족 | 뿜뿜(일)·나르(희)·모비(전)·오르카(전) | 침수 싸움 | 우리 배 턴 끝 침수량 −2%p | 우리 공격이 올리는 적 침수량 +25% |
| 심연 교단 | 옥토(일)·젤리(희)·크라키(전)·램프(전) | 수중·어둠 | 수중 계열 흘수선 아래 명중 시 침수 +2%p | 상대 궤적 표시 길이 −30% |
| 서리엄니 쇄빙대 | 핀(일)·왈러스(희)·핑구(희)·소오(영) | 관통 | 관통 칸 +1 | 철판 블록 피해 +30% (관통의 약점 보완) |
| 파도 사냥꾼 | 수리(일)·셀던(희)·바라(희)·돌피(영) | 흘수선 | 물수제비 튕김 +1회 | 흘수선 명중 시 적 연료 −15 |
| 산호초 이웃 | 톡(일)·쿡(희)·코리(영)·볼케(전) | 방어·수리 | 선체 블록 내구도 +8% | 매 내 턴 시작에 ‘구멍’ 블록 1칸 자동 수리 |
| 번개 기습대 | 히포(일)·모레이(영)·볼트(전)·만타(전) | 기동·방해 | 이동 연료 소모 −20% | 우리 공격에 맞은 적 해적 쿨다운 +1턴(최대 3턴) |

균형 기준: 3세트 누적 효과 ≈ 해적 1명의 등급 한 단계 차이. sim_runner 에서 승률 55% 넘는 세트 조합이 없어야 한다.

### 연결 절 수정 (짧게)
- §4.3 데이터 형식: 세트는 해적 JSON 이 아니라 별도 `sets.json`(id, 멤버 id 4개, 2세트·3세트 효과, `nameKey`) 에 둔다. pb_data 가 “해적마다 정확히 한 세트” 검사.
- §4.5 출전 코스트: 세트 맞추기와 코스트의 교환 한 줄.
- §5 AI(적 덱, §5.3 성격 또는 §15.3): 세력 덱은 대표 종족 세트를 켜고 나온다 → 세트를 적에게서 배운다.
- §13.3 전투 준비: 내 발동 세트와 상대 발동 세트 아이콘.
- §13.4 HUD: 위 양쪽에 발동 세트 아이콘, 누르면 효과 설명.
- §13.7 선원 편성 탭 덱 평가: 발동 세트(2/3), 한 명 모자란 세트 힌트, 보유 목록 카드에 세트 아이콘·세트 필터.
- §13.9 해적보감: 카드에 세트 아이콘, 정보 탭에 소속 세트·멤버 4명(보유 여부)·2/3세트 효과.
- §14 문자열 키: `set_<id>_name`, `set_<id>_bonus2`, `set_<id>_bonus3` (ko·en).

## 2. 계획서 수정 (`Pirate Busters 개발 계획서.md`)
- 12장 끝에 **`A3 해적 세트 효과 — pb_data, pb_sim, pb_ai, app`** 추가.
  - 선행: R1(40명·상태 효과), R4(선원 화면 완성판), A2(해적보감 표시).
  - 작업: `sets.json` + 스키마 검사(§4.7) / pb_data 매치 시작 세트 판정 → ‰ 효과 목록 / pb_sim 효과 10종(수치 보정 + 규칙형: 버팀·부활·쿨다운 0·자동 수리·쿨다운 +1·연료 감소) 시드 고정 해시 테스트 / AI 세력 덱 세트 반영 / 편성·전투 준비·HUD·해적보감 표시 / ko·en ARB / Remote Config `set_*` / sim_runner 균형.
  - 완료 조건: 10세트 × 2·3세트 효과가 시나리오 테스트로 설계서 수치와 같음, 해적이 쓰러져도 효과 유지, 같은 시드 해시 동일, 승률 55% 초과 조합 없음, 두 언어 글자 잘림 없음.
- 머리의 `설계서 동기화:` 해시·날짜 갱신 (`tool/check_doc_sync.dart` 의 FNV 해시).

## 3. ADR
`docs/DECISIONS.md` 에 **ADR-031 해적 세트 효과(테마 10세트, 전투 시작 고정)를 A3 로** — 이유: 계열 세트는 몰빵 덱을 만들어 §4.1 상성을 약하게 함, 시작 고정은 §3.5 와 같은 방식이고 pb_sim 판정이 단순.
