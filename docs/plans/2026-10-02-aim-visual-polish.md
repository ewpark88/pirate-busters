# 조준 표시 다듬기 (당겨 쏠 때 새총·호·링·궤적 점선)

## Context
당겨서 쏠 때 나오는 조준 표시가 조잡하다는 사용자 피드백. 지금 표시는 선 몇 개와 원을 겹친 정도다
(`app/lib/game/view/aim_painter.dart`).
- 고무줄: 1.6px 선 두 개와 끝 점 하나
- 각도 호: 흰 선, 수평 안내선 하나
- 힘 링: 반투명 흰 원과 등급색 호
- 궤적: 검은 테를 두른 단색 원
- 각도 숫자는 맨 글자, 힘 숫자만 알약에 들어 있음
→ 요소마다 모양이 달라 한 벌로 안 보인다.

규칙(설계서 §10.4)은 그대로 둔다: 고무줄·각도 호·힘 링·각도/힘 숫자·앞 30% 궤적,
고른 간격의 테두리 점이 발사 방향으로 흐르고 멀어질수록 흐려짐, 저사양에서는 멈춤, 등급색(§10.5).
렌더만 바꾸므로 pb_sim·밸런스·설계서는 건드리지 않는다.

## 바꿀 것 (렌더 전용)

### 1. 궤적 점 — `AimPainter.trajectory`
- 단색 원 대신 **진주알**처럼 그린다: 아래쪽에 옅은 그림자, 등급색 몸통, 위쪽 왼편에 작은 흰 하이라이트.
  테두리는 얇은(0.8px) 어두운 색으로 바꿔 무겁지 않게 한다.
- 크기는 앞 3.4px에서 끝 1.6px로 매끄럽게 줄이고, 흐려지는 정도(`dotAlpha`)는 지금 그대로 둔다(테스트 유지).
- 맨 끝 점 자리에 등급색 **작은 화살촉(셰브론)** 을 붙여 ‘이 방향으로 계속 간다’는 느낌을 준다.

### 2. 새총 — `AimPainter.sling`
- 고무줄: 어두운 외곽선 위에 고무색 선을 두 겹 그리고, 많이 당길수록 조금 가늘어지게 한다(늘어난 느낌).
- 끝: 점 대신 조준 방향에 맞춰 돌린 **가죽 주머니**(둥근 사각형)에 등급색 탄알을 하나 담는다.
- 새총 갈래(발사 지점 양옆)에 작은 나무색 기둥 두 개.

### 3. 각도 호
- 수평에서 조준 방향까지 **반투명 부채꼴**(흰색 15%)을 깔고 그 위에 호를 그린다.
- 호 바깥에 15° 마다 작은 눈금. 수평 안내선은 점선으로 바꾼다.

### 4. 힘 링
- 지금의 반투명 원 대신 **10칸 구간 링**: 어두운 트랙 위에 칸 사이 틈을 두고, 채워진 칸은 등급색.
- 힘 100% 이면 링 바깥에 얇은 빛 테(등급색, 낮은 투명도)를 둘러 ‘최대’가 보이게 한다.

### 5. 숫자 — `AimLabels.draw`
- 각도도 힘과 같은 **알약**에 넣어 두 숫자의 모양을 맞춘다(테두리는 지금의 금색 `0xFFC9962E`).
- 자리 함수 `angleAt`·`powerAt` 은 그대로 둬서 기존 테스트가 유지되게 한다.

## 파일
- `app/lib/game/view/aim_painter.dart` — 궤적 점·호·링. 300줄을 넘으면 새총 부분을
  `app/lib/game/view/aim_sling.dart` 로 나눈다(`AimPainter.sling` 이름은 유지해 호출부·테스트를 그대로 둔다).
- `app/lib/game/view/aim_labels.dart` — 각도 알약.
- `app/lib/game/view/shot_view.dart` — 호출부. 공개 이름이 같으면 바꿀 것 없음.
- 화면에 새 글자를 넣지 않으므로 l10n 변경 없음.

## 검증
1. `app/test/aim_painter_test.dart`, `app/test/rarity_fx_test.dart` 그대로 통과(공개 함수 이름·자리 계산 유지).
   새 테스트: 구간 링 칸 수 계산(힘 0 / 55% / 100%), 화살촉이 마지막 점 방향을 향하는지.
2. 눈 확인용 임시 위젯 테스트로 조준 표시를 PNG로 그려 scratchpad 에 저장 → 열어 보고 다듬는다
   (일반·전설 등급색, 각도 20°/60°, 힘 30%/100%, 좌우 방향). 확인 뒤 임시 파일은 지운다.
3. `bash tool/verify.sh` 통과.
4. 실제 손맛은 사용자가 `flutter run` 으로 테스트 전투에서 확인.

## 범위 밖
- 판정·궤적 계산(pb_sim)·조준 입력(`pull_aim.dart`)은 바꾸지 않는다.
- R1a 단계 작업과 섞이지 않게 커밋은 사용자가 요청할 때 따로 한다.

## 2차 (사용자 피드백: "조준선대로 쏘면 맞을 만큼 정밀하게, 아직 어색하다") — ADR-076
- 점선 앞 20% 로 (설계서 §2.2·§10.4 사용자 결정 반영, 계획서 해시 갱신).
- 호·새총·각도 숫자를 실제 발사 방향(조준 각도 + 배 기울기, `session.launchTilt`)으로.
- 놓을 때 50ms 미끄러짐 제거(`PullAim.release(ms:)`).
- 점: 진주알·화살촉 → 같은 크기의 작은 점. 각도 눈금 제거, 링 가늘게.
- 테스트: 발사 방향 = 조준+기울기(`battle_session_test`), 미끄러짐 제거(`pull_aim_test`).
