# A50 조선소 화면 정리 (건조 화면 구조 개선) — 계획


## Context (왜)
사용자 평가: 조선소 화면이 "정리가 안 되어 있고 조잡하다". 골든(`app/test/goldens/shipyard_ko_low.png`·`_high.png`)과 코드(`app/lib/shipyard/`)에서 확인한 원인:

1. **수치 줄 과밀** — 칩 8~9개(포인트·흘수선·속도·1칸 연료·탱크·선실·모듈·선장실·저장 불가)가 한 줄. 1280×720 에서 오른쪽이 잘려 가로 스크롤. 저장을 막는 값(포인트·선실·모듈·선장실)과 참고 값(흘수선·속도·연료·탱크)이 같은 모양이라 무엇을 봐야 할지 모른다.
2. **팔레트 뒤죽박죽** — 재질 5·선실·모듈·돛대 5·지우기 약 20개가 `Wrap` 한 덩어리. 칩 너비가 들쭉날쭉, 선실이 망사와 포문 사이에 끼는 등 순서가 섞이고, 잠긴 것과 쓸 수 있는 것이 섞인다. 낮은 해상도에선 아래가 잘린다. 지우기가 맨 끝에 묻혀 있다.
3. **격자 패널 공간 낭비** — 큰 패널 안에 배가 작게, 검은 바탕 위에 떠 있다. 흘수선 아래·위 구분이 약하다.
4. **아래 줄 혼선** — 되돌리기가 `KitArt.back`(뒤로 화살표)과 같은 그림이라 '나가기'로 읽힌다. 설계도 탭·되돌리기·저장·출전이 한 줄에 같은 무게로 붙어 있다.
5. **위 오른쪽 아이콘 뜻 불명** — 금화 아이콘 = 배 업그레이드, 파란 도면 = 추천 설계도 불러오기. 글자가 없어 알 수 없다.

**범위:** 설계서 §13.6 '건조' 탭 배치(왼쪽 격자·오른쪽 팔레트·위 건조 포인트, 수치 즉시 갱신, 되돌리기, 설계도 3칸)를 **그대로 지키고 배치·묶음·시각만 정리**한다. 탭 3개(건조/선형/설계도)·시험 발사·공유 코드·이름 짓기는 R2 몫이라 하지 않는다(절대 규칙 1). 끝난 M5 화면을 고치므로 계획서 12장 끝에 **A50** 으로 넣는다(절대 규칙 11, 착수 때 번호 다시 확인). 설계서·BALANCE.md 는 바꾸지 않는다. 규칙·판정(`pb_sim`) 변경 없음.

### 1) 수치를 두 층으로 나눈다 — `shipyard_stats.dart` (새 파일)
- **저장 조건 4개**(포인트·선실·모듈·선장실)는 격자 패널 머리에 작은 게이지/칩으로. 포인트는 막대 게이지(사용/한도), 나머지는 `n/m`. 어긋나면 빨강 + '저장 불가' 사유 한 줄(지금 `cannotSave` 칩 대신, 왜 막혔는지 보이게).
- **참고 수치 4개**(흘수선·속도·1칸 연료·탱크)는 ~~팔레트 패널 맨 아래 2×2 표~~ → 구현 때 **격자 패널 아래 한 줄**로 바꿨다(360dp 높이에서 팔레트 카드 자리를 지키려고). 가로 스크롤 없앤다.
- 계산은 지금 `_stats` 그대로(`_model.stats`, `hull`), 위치만 옮긴다.

### 2) 팔레트를 종류 탭으로 묶는다 — `tool_palette.dart` 재구성
- 위에 작은 `PbTabs` 3개: **재질 / 모듈 / 돛대**. (선택 상태는 `ToolPalette` 안 로컬 상태, 고른 도구가 속한 탭으로 시작)
- 탭 안은 **같은 크기 카드 2열 격자**(그림 크게 28~32, 이름, 아래에 포인트 또는 🔒+골드). 칩 너비 들쭉날쭉 없앰.
- 순서: 쓸 수 있는 것 먼저, 잠긴 것 뒤(같은 묶음 안에서 기존 enum 순서 유지).
- **선실·지우기**는 탭과 상관없이 팔레트 아래 고정 줄에 둔다(자주 쓰고, 선실은 모듈 한도 밖이라 따로 보이는 게 맞다).
- 잠금·해금 흐름(`lockedGold`, `onLocked` → `unlockTool`)은 그대로.
- 설계서 §13.6 "빨간 점"(지금 골드로 열 수 있는 것)은 이번에 카드에 붙인다 — 이미 설계서에 있는 규칙이고 아직 없다. 탭 이름 옆에도 점. (범위가 넓다고 판단되면 빼도 됨 — 승인 때 결정)

### 3) 격자 패널 시각 — `ship_grid_editor.dart`·`ship_grid_view.dart`
- 패널 바탕을 검정 대신 하늘→바다 그라데이션, 흘수선 아래는 옅은 물빛으로 채운다(지금 파란 선 하나 → 물 높이로 읽힘).
- 셀 크기 계산은 머리 게이지 높이를 뺀 영역에서. 배를 가운데·크게.
- 틀 밖 칸은 지금처럼 안 그림. 빈 틀 칸 선은 조금 더 옅게.

### 4) 아래 줄·위 버튼 — `shipyard_actions.dart` (새 파일)
- 되돌리기 아이콘을 뒤로 화살표와 다른 '되돌리기(↶)' 그림으로. 새 그림이 없으면 `Icons.undo` 를 `PbIconButton` 에 맞춰 쓴다(그림 목록 확인 후 결정).
- 저장(금색 주 버튼)·출전(보조)은 오른쪽, 설계도 3칸 탭은 왼쪽 — 위치는 유지하되 사이 간격·크기 통일.
- 위 오른쪽 두 아이콘에 짧은 글자 붙인 버튼(`배 강화`, `추천 설계도`) — 기존 l10n `shipUpgrades`·`loadPreset` 재사용, 새 키는 필요할 때만 ko·en 동시 추가.

### 5) 파일·줄 수
- `shipyard_screen.dart` 는 배치만 남기고 `_stats`·`_actions` 를 새 파일 2개로 뺀다(300줄 규칙).
- 모델(`shipyard_model.dart`)·저장(`FleetStore`)·업그레이드 창(`ship_upgrade_sheet.dart`)은 동작 변경 없음.
