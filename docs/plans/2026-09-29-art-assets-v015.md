# 아트 에셋 v0.15 배치 (art/ 원본 + app/assets 게임용)

## Context
사용자가 `D:\Projects\이미지참고용\pirate_busters_assets_v0.15` 를 만들었다. 17MB, 1,340개 파일이고, SVG 원본·PNG 1x/2x/3x·anims.json·tokens.json·Flame 참고 코드가 들어 있다. 이것을 권장 구조(Flutter + Flame)대로 저장소에 넣는다.

이 저장소는 루트가 Dart 워크스페이스이고 Flutter 프로젝트는 `app/` 이다. 그래서 권장 구조의 `assets/`·`pubspec.yaml` 은 `app/` 아래에 둔다.

사용자 결정:
- `art/` 는 git 에서 제외한다.
- `pb_anim.dart` 는 이번에 `art/` 에만 두고, M4 에서 Flame 을 추가할 때 `app/lib` 로 옮긴다.

## 작업 위치 (다른 세션 보호)
- 지금 작업 트리는 다른 세션이 M3(`pb_sim`) 구현 중이다(`feat/M3-motion-flood`, 미커밋, git 상태를 건드리지 말라는 요청).
- 그래서 **별도 git worktree** `D:\Projects\pirate-busters-assets` 에서 새 브랜치 `feat/M4-assets` 로 작업한다. 기준은 `cc96996`(최신 문서 커밋, pb_sim 미완성 작업은 들어 있지 않음).
- 다른 세션의 체크아웃과 파일은 건드리지 않는다. 시작할 때 SendMessage 로 알린다.

## 구성
```
art/pb_assets_v0.15/                패키지 전체를 그대로 복사 (.gitignore 에 art/ 추가)
app/assets/images/                  PNG 는 @2x 만, 이름에서 "@2x" 를 뗀다
  characters/<id>/                  <id>_<team>_battle.png
    parts_<team>/                   부위 PNG + parts.json (원본 parts_<team>@2x)
    parts_battle_<team>/            전투 외곽선 부위 PNG (원본 parts_battle_<team>@2x, json 없음 → parts_<team>/parts.json 에 offset −14·pivot +14)
  ship/tiles/ ship/rooms/ ship/rig/ 원본 png/tiles, rooms, rig
  fx/ fx/impact/ fx/collapse/       원본 png/fx
  ui/portraits/ ui/kit/ ui/icons/   원본 png/ui
app/assets/data/anims.json          원본 anims/anims.json
app/assets/data/tokens.json         원본 style/tokens.json
```
- 캐릭터 8명: octo, bones, sword, otter, puffer, gull, shark, turtle. @2x 기준 파일 약 487개, 약 5.4MB.
- `app/pubspec.yaml` 의 `flutter: assets:` 에 폴더마다 한 줄씩 적는다. data, ship 3개, fx 3개, ui 3개, 캐릭터 8명 × (루트 + parts 2개 + parts_battle 2개) = 40줄.

## 복사 스크립트 (다음 버전 재사용)
- `tool/import_assets.dart <패키지 경로>`: art/ 복사, @2x 만 골라 이름 바꿔 `app/assets/` 로 복사, `pubspec.yaml` 에 빠진 에셋 폴더가 있으면 목록을 출력하고 실패한다.
- 이름 바꾸기와 대상 경로 계산은 순수 함수로 두고 `tool/test/import_assets_test.dart` 에서 테스트한다. 테스트 이름은 한국어로 쓴다.
- v0.16 이 나오면 같은 명령으로 교체한다.

## 문서
- `docs/ASSETS.md`: 폴더 구조, @2x 만 넣는 이유(Flame 은 해상도별 자동 선택을 쓰지 않음), 갱신 절차, battle 부위 offset 규칙, pb_anim.dart 를 M4 에서 옮길 때 경로를 `assets/data/anims.json` 으로 바꾼다는 메모.
- 개발 계획서 M4 ‘해적 렌더’ 항목: “SVG 패키지는 착수 때 ADR” 대신 “v0.15 PNG 부위 스프라이트 + pb_anim.dart(art/ 참고 구현)를 app/lib/game/anim/ 으로 옮긴다”로 고친다. 설계서는 고치지 않는다.
- ADR-026 “아트 에셋 v0.15: PNG 부위 스프라이트, art/ 는 git 제외, @2x 만 앱에 포함”.

## 설계서와 어긋나는 점 (보고만, 수정은 사용자 판단)
- MVP 해적 12명 중 에셋이 없는 5명: 스타리·팡·히포·폴리·뿜뿜. 시작/확정 보상인 폴리·팡도 여기에 들어간다. 본즈는 MVP 12명에 없다.
- 예시 배가 18×12 격자, 블록 32px 이다. 설계서 선형은 슬루프 12×8 ~ 갤리온 18×11 이다.
- 화풍이 ‘2.5등신·해 질 녘 역광·가죽·금속’ 이다. 설계서 §10.1 은 플랫 2D 벡터·진갈색 외곽선 규칙이다.
- 강습 계열 이름이 ‘boarding 백병’ 으로 되어 있다.
