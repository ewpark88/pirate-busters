# 퀄리티 5차 (A33): 피격 내구도 표시·HUD·연료 디자인·조준선 손맛


## Context
사용자 피드백: "폭탄에 맞은 배의 내구도 표시가 부자연스럽고, 조준선도 부자연스럽다."
탐색으로 찾은 원인:

**내구도**
1. HUD 선체 막대(`app/lib/ui/hud/top_bar.dart:124-174`)가 `session.state`(발사 순간에 시뮬이 끝난 최종 상태)를 읽는다 → **탄이 날아가는 중에 막대가 먼저 줄어든다.** tween·잔상 막대도 없고, 연출 중엔 HUD 가 25% 로 흐려져(`battle_hud.dart:70-73`) 변화가 잘 안 보인다.
2. 배 그림(`ship_view.dart:209-218`)은 `landed`(첫 착탄) 순간 최종 격자로 통째로 바뀐다 → 연사·분열·다중투하는 **뒤 탄이 닿기 전에 칸이 이미 부서져 보이고**, 파괴 조각(shatter)은 칸이 사라진 뒤에 나온다.
3. `flashCell`(`cues_crew.dart:29-32`)이 최종 상태를 보고 판단해 **이번 탄에 부서진 블록은 번쩍이지 않는다**(가장 센 한 방이 가장 약한 반응).
4. 손상 단계는 3단계 즉시 교체(`damage_layer.dart`), 선체 피해 숫자가 없어(설계서 §10.4 :839 "맞은 곳 위에 피해 숫자"인데 해적만 구현) 작은 피해는 안 맞은 것처럼 보인다.

**조준선**
1. 당기는 동안 카메라가 줌아웃하며 앞으로 이동(`camera_director.dart:156-159`) → **해적·새총이 손가락 아래에서 미끄러져 나간다.**
2. 새총·점선·숫자가 월드 단위라 세게 당길수록(줌아웃) 화면에서 작아진다. 일반 등급 흰 점선(반지름 1.9)은 거의 안 보인다.
3. 각도·힘 숫자가 발사 지점 **아래 32px**(`aim_labels.dart:33`) → 아래·뒤로 당기는 엄지에 가린다.
4. 힘 10% 미만에서는 새총까지 통째로 숨겨(`shot_view.dart:214`) 누른 직후 반응이 없다가 16px 에서 갑자기 나타난다.
5. 짧게 당길 때 각도가 1px 에도 크게 튄다(데드존·평활 없음, `pull_aim.dart`).
6. **유도탄 미리보기 버그:** `ShotPath.predict`(`app/lib/battle/shot_path.dart:13-32`)가 `_arm`(`pb_sim/.../ammo_rules.dart:102`)을 거치지 않아 중력 포물선을 그린다(실제는 중력 없음+조향).
7. 매 프레임 최대 300틱 전체 탄도를 다시 계산(저사양 끊김 위험).

## 단계·브랜치·문서
- 새 단계 **A33 "퀄리티 5차: 피격 내구도 표시·조준선 손맛"** 을 계획서 12장 끝에 추가(절대 규칙 11), **ADR-088** 기록, `docs/plans/README.md` 색인 한 줄.
- 설계서 근거: §2.2(:43 앞 20% 점선, :44 놓으면 취소), §2.1(:34 줌아웃), §10.4(:839 피해 숫자, :845 조준 표시), §13 HUD(:988 선체 내구도). 설계서 문장 변경은 필요 없음(§13.4 선체 막대 예외 문장만 제안).
- 작업 트리는 A32 세션과 공유 중이고 `cues_crew.dart`·`ship_view.dart`·`battle_cues.dart` 가 A32 미커밋 파일과 겹친다. → **A32 커밋 뒤 `feat/A33-durability-aim` 을 별도 worktree(`D:/Projects/pirate-busters-a33`)로 A32 끝에서 따서** 작업한다. 브랜치 전환·worktree 생성 전에 사용자에게 알린다.

## 구현

### 1. pb_sim: 블록 피해 이벤트 (결과 불변)
- `SimEventKind.blockHit` 추가: `cell`, `side`, `value` = 실제 깎인 양(남은 hp 로 자른 값), `y` = 남은 hp. 렌더용 이벤트라 상태 해시 불변.
- 내보내는 곳: `combat/impact.dart:51 hitBlock`, `flight.dart:140,160`(관통·물수제비), `unique_moves.dart:41`, `fire.dart:94`(턴 끝 화재). `ShipGrid.damage` 앞뒤 hp 차이로 계산.
- 테스트: 이벤트 합 = 격자 hp 감소량, 기존 시드 해시 그대로.

### 2. app: 착탄 시점에 맞춘 "보이는 격자"
- `playback.dart` 에 `LiveGrid`(=`GridSnapshot` 사본 + `apply(SimEvent)`) 추가. `ShotPlayback` 이 `before` 에서 시작해 `takeDue()` 로 나온 `blockHit`/`blockDestroyed`/`blockCollapsed`/`repaired` 를 그 틱에 적용.
- `ship_view.dart:213-218` 는 `landed` 분기 대신 연출 중이면 `live` 를 그린다 → 탄마다 차례로 부서짐, shatter 와 칸 사라짐이 같은 프레임.
- `flashCell` 은 `blockHit` 이벤트로 판단(부서진 칸도 번쩍).
- 연출이 없을 때(상대 턴 스킵 등)는 지금처럼 `session.state`.

### 3. HUD 디자인 변경: 공용 게이지 + 선체·침수·선원 패널 (사용자 요청)
지금은 `LinearProgressIndicator`(8px, 기본 머티리얼 모양) + 아이콘 글자 줄이라 밋밋하고, 피해 순간 변화가 안 보인다.
- **공용 `HudGauge`** (새 파일 `app/lib/ui/hud/hud_gauge.dart`, CustomPaint): 둥근 캡슐 막대, 안쪽 어두운 홈 + 위쪽 하이라이트(입체감), 채움은 세로 그라데이션, 10% 눈금, 막대 위에 퍼센트 숫자(그림자). 앞 막대는 0.18s 에 따라가고 **잔상 막대**(줄 때 흰→빨강, 찰 때 밝은 초록 미리 채움)가 0.45s 머문 뒤 0.4s 따라온다. 값이 줄면 막대가 짧게 흔들리고 테두리가 번쩍(흔들림 줄이기 설정 시 생략). 낮음 구간(선체 ≤ 격침 기준+10%p, 연료 ≤ 20%)은 색이 경고색으로 바뀌고 천천히 맥박.
- **`SideStatus` 재구성** (`top_bar.dart` → 새 `side_status.dart` 로 분리, 300줄 규칙): 진영색 리본 머리(배 아이콘 원형 배지가 왼쪽에 겹쳐 붙음) + 선체 `HudGauge`(굵게 14px) + 아래 한 줄에 침수 물방울 아이콘·숫자(%, 늘면 파랗게 깜빡), 선원 얼굴 아이콘 n개(쓰러진 해적은 회색 ×). 오른쪽 배 패널은 좌우 대칭(배지 오른쪽).
- 선체 값은 `session.visibleHull(side)`(연출 중이면 live 합 / `initialTotalHp`).
- **연출 중 흐림:** 설계서 §13.4 :995 는 연출 중 위쪽 패널을 흐리게 하라고 한다. 피해 순간만 선체 막대를 0.6s 또렷하게 하려면 설계서 문장 추가가 필요 → **"단, 선체 내구도 막대는 피해를 받는 순간 잠깐 또렷해진다"를 §13.4 에 넣자고 제안**(승인 전까지는 흐린 채 잔상만).

### 3b. 연료 HUD 디자인 변경 (`move_controls.dart`, 사용자 요청)
- 좌우 버튼: 원형 버튼(지름 52, 진영색 테·안쪽 그라데이션) 안에 화살표, 누르는 동안 눌림(0.92 축소 + 안쪽 그림자 + 빛 테), 잠김이면 자물쇠 겹침. 글자(전진/후퇴)는 버튼 아래 작게(기존 l10n 키).
- 가운데 연료: 같은 `HudGauge`(너비 96, 연료통 아이콘 배지). **누르고 있는 동안 갈 수 있는 끝까지 썼을 때 남을 양을 잔상으로 미리 표시**(이미 있는 `setMovePreview`·`reach` 값을 사용), 움직이는 동안 막대가 실시간으로 줄고, 내 턴 시작 회복은 초록 잔상으로 차오름. 0 이면 지금처럼 깜빡(설계서 §2.7 :125). 묶임이면 막대 위에 쇠사슬 무늬 + ‘묶임’.
- 새 글자가 생기면 ko/en ARB 같은 커밋.

### 4. 선체 피해 숫자 (설계서 §10.4 :839)
- 한 번의 `impact` 뒤에 따라온 `blockHit` 값을 합쳐 착탄 지점 위에 `-N` 을 기존 `fx_text.dart` 로 띄운다. 한 방 크기(`HitWeight`, A32)로 크기·색. 같은 자리 연속이면 위로 쌓아 겹침 방지(해적 숫자에도 적용).
- 문자열은 기존 피해 숫자 키 재사용(새 키가 필요하면 ko/en 동시).

### 5. 손상 단계 전환
- `DamageLayer` 단계가 바뀐 칸만 0.15s 동안 균열/구멍이 커지며 나타나게(scale 0.6→1 + 알파). 칸 단위 짧은 덧그림이라 Picture 캐시는 유지.

### 6. 조준: 손가락 아래 고정
- `camera_director.dart` 조준 줌: 줌아웃 기준점을 **누른 해적의 화면 위치**로 고정(해적이 손가락 근처에 머물고 앞쪽 시야만 넓어짐). 카드 선택 줌인과 겹치면 줌인을 끊고 조준 줌으로 바로 넘김.
- 새총·호·링·점선·숫자 크기를 `1/zoom` 으로 보정해 화면 크기 일정(`aim_sling.dart`, `aim_painter.dart`, `aim_labels.dart`). 점 반지름 화면 3px·테 1.2px, 끝 흐림 0.45→0.55.
- 숫자 알약을 발사 방향 쪽 **위**(해적 머리 위 앞쪽)로 옮김.

### 7. 조준: 반응·감도
- 누르는 즉시 새총·힘 링을 옅게(최소 힘 미만 표시) 보여 주고, 10% 를 넘으면 진하게. 점선은 지금처럼 10% 이상에서만.
- `pull_aim.dart`: 당긴 길이 24px 미만에서는 각도를 이전 값에 저역통과(가중 0.35)로 따라가게, 이상이면 즉시. 힘 곡선은 선형 유지(설계서·BALANCE 무관, 감도만).
- 놓기 50ms 되돌리기는 유지하되 점선도 같은 값(되돌린 값)을 그려 보인 것과 쏜 것을 맞춤.

### 8. 조준: 미리보기 정확도·성능
- pb_sim `ammo_rules.dart` 의 `_arm` 을 `armShot(p, reach)` 로 공개(`pb_sim.dart` export)하고 `ShotPath.predict` 가 같이 부름 → 유도탄 점선이 실제와 같음. 조향(`steerHoming`)도 예측 루프에 넣는다.
- 예측 결과를 `(angle, power, tilt)` 키로 캐시해 손가락이 멈춰 있고 기울기 같으면 재계산 생략.

## 검증
- pb_sim: `blockHit` 합 = hp 감소량, 기존 재현성 해시 그대로, 유도탄 `predict` 앞 20% 가 실제 `runVolley` 경로와 같음.
- HUD: `HudGauge` 위젯 테스트(값 감소 → 앞 막대 즉시·잔상 지연, 연료 미리보기 잔상), HUD 골든(내 턴·피격 직후·연료 이동 중·연료 0·묶임, ko/en)과 전후 비교 캡처.
- app 테스트: LiveGrid 가 틱 순서대로 칸을 깎음(연사 2발 → 첫 착탄 뒤 한 칸만 깎임), 발사 직후 HUD 값이 그대로이고 착탄 뒤 줄어듦, HullBar 잔상 시간, 각도 평활, 숫자 알약 위치.
- 전투 골든 갱신(조준 중·피격 직후 프레임), 더미배 연습으로 연사·폭발탄·유도탄 전후 캡처를 `docs/quality/` 에.
- `bash tool/verify.sh` 통과, `rules-reviewer` 검토. 실기기 손맛은 이월 목록에.
