# 보스: 새 그림 없이 표시만 (A41 제안)

## Context
- 사용자 지시(2026-10-07): 보스를 따로 그리지 않는다(창작 부담). 보스전은 새 보스를 만들지 않고, 사용자가 보스전임을 알 수 있게 화면에 표시한다.
- 조사 결과: 앱에는 보스 전용 이미지가 없다. 보스 배는 일반 선체에 배 단계 +1, 참나무 돛대 Lv2, AI 보통/어려움, 기믹으로 차이를 낸다. 원본 `art/pb_v0.24_main/boss/` 의 기믹 부품은 `tool/import_assets.dart:40` 에서 R3까지 가져오지 않도록 막혀 있다. 계획서 R3(`:445`)에 "보스 12식 그림·크라켄·충각·왕관 깃발·아귀 등불"이 남아 있다.
- 사용자 답변:
  - 해역 1 기믹(1-5 철판, 1-12 한계선)은 **유지**한다.
  - 해역 2~6 고유 보스 기믹과 그림은 **만들지 않는다**.
  - 난이도는 **지금처럼 유지**한다. 배 단계 +1·돛대·AI·기믹이 이미 있다.
  - 표시는 **적 배 붉은 표식 + 화면 가장자리 붉은 테**로 한다.

## 1. 기준 문서 수정 제안 (사용자 승인 뒤, 내가 직접 고치지 않음)
- 설계서 §5.4: 해역 2~6 보스 배와 고유 기믹 표를 지우거나 "해역 1 기믹 재사용 또는 기믹 없음"으로 바꾼다. 아래 문구를 더한다.
  - "보스는 전용 그림을 쓰지 않고 일반 선체로 그린다."
  - "보스전은 적 배 붉은 표식과 화면 가장자리 붉은 테로 알린다."
- 설계서 §13(전투 화면)에 보스 표시 한 줄을 더한다.
- BALANCE.md A5.4: 해역 2~6 기믹 수치 줄을 정리한다(삭제 또는 '없음').
- 승인되면 `/doc-sync` 를 한다.
  - 계획서 R3 `:445` 에서 "보스 12식 그림·크라켄·충각·왕관 깃발·아귀 등불(`boss/`)"을 지운다.
  - 11장 미정 `:526`(크라켄 촉수)을 지운다.
  - 해시를 갱신하고 ADR을 추가한다("보스 전용 그림·고유 기믹 폐기, 표시로 대체").

## 2. A41 보스전 표시 (계획서 12장 끝, 절대 규칙 11) — `app` 만
브랜치는 `feat/A41-boss-marks` 로 하고, A40 머지 뒤 main에서 딴다. 공유 작업 트리이므로 내 경로만 add 한다.
- **화면 가장자리 붉은 테**: 새 위젯 `app/lib/ui/hud/boss_vignette.dart` 를 만든다.
  - `IgnorePointer` + 옅은 붉은 방사형 비네트이고, 천천히 숨쉬듯 깜빡인다. `kit_motion` 의 기존 곡선을 쓴다.
  - 접근성 설정에서 움직임 줄이기가 켜져 있으면 고정으로 둔다.
  - `battle_screen.dart:270` 근처에서 `widget.stage?.isBoss == true` 일 때 HUD 아래층에 넣는다.
- **적 배 붉은 표식**: 렌더 전용으로 그린다.
  - `app/lib/game/view/` 에 보스 표식을 두거나 `gimmick_marks.dart` 옆에 함수를 더한다. 적 배 위에 붉은 왕관/해골 표식과 옅은 붉은 윤곽 빛을 Canvas 도형으로 그리고, 새 이미지는 만들지 않는다.
  - `ship_view.dart:258` 근처에서 적 쪽이고 보스 스테이지일 때만 그린다. 보스 여부는 `battle_game` 에 stage 를 넘기는 기존 경로로 전달한다.
- **배너**: 지금은 기믹이 있을 때만 뜬다(`battle_screen.dart:270`). `isBoss` 일 때 뜨게 바꾸고, 기믹 줄은 기믹이 있을 때만 보인다. 해역 2~6 기믹 없는 보스에 대비한 것이다.
- 새 글자는 없을 것으로 본다. 생기면 ko·en ARB에 같은 커밋으로 넣는다.
- 테스트(한국어 이름)를 더한다.
  - 보스 스테이지에서 비네트와 배너가 보이고, 일반 스테이지에서는 보이지 않는다(위젯 테스트).
  - 표식은 보스일 때만 그려진다.
