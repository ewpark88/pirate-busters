# R1a 행동 모듈·상태 효과 엔진 — 세부 계획 (2026-10-02)

브랜치 `feat/R1a-sim-modules` (main e2a75c3 + 9ea9052). 계획서 4장 끝 ‘R1 해적 40명’ 절, ADR-074.

## 조사 결과 요약
- **행동 모듈 구조가 없다.** 행동은 `AmmoType` 별 `switch`(`combat/hit_effects.dart`·`ammo_rules.dart`·`volley.dart`)로 갈린다. 해적 JSON 의 `projectile`·`onHit` 은 반경·피해만 읽는다. 해적별 차이는 `ammoParam` 정수 하나(`repairCells`·`delayed`)뿐이다.
- **사다리 13종 × 5칸 데이터는 있다**(`app/assets/game/ammo.json`, `AmmoType.fire`·`chain`). 그러나 화염탄·연쇄탄은 `hit_effects.dart:96-104` 에서 폭발 착탄으로만 처리된다.
- **지속 상태를 담을 곳이 없다.** `TurnEffect` 는 턴 시작 한 번짜리 예약(mineBlast·flockDrop·biteAgain)만 표현한다. 턴 끝에 화재 단계도 없다(`match.dart` 242행 주석만 있음).
- 상태를 해시에 넣으면 빈 목록이어도 해시가 바뀐다 → 골든 100판과 `determinism_test.dart` 고정 해시를 다시 만든다(이유를 커밋에 적는다).
- 300줄 규칙: `hit_effects.dart`(240)·`ammo_rules.dart`(229)는 여유가 없어 새 파일로 나눈다.

## R1a-1 설계 결정 제안 (설계서·BALANCE 반영 전 승인 필요)
- **P1 능력 스키마 (§4.3):** 범용 모듈 조립 대신 ‘탄종(`ammo`) + 고유 능력(`ability`)’ 두 축으로 한다. 탄종이 projectile·onHit·onLand 를 정하고, 해적 JSON `ability: {"type": "<key>", <정수 인자…>}` 가 onTap 과 고유 효과를 정한다. pb_sim 에는 `Ability` enum + 정수 인자. 모듈 수(탄종 13 + 능력 키)는 약 20개를 유지한다. → 설계서 §4.3 의 모듈 JSON 예시를 이 형식으로 고치자는 제안.
- **P2 상태 지속의 뜻 (§4.2):** ‘다음 상대 턴’ = 효과를 건 쪽의 턴이 끝난 뒤 이어지는 상대 턴 1번. 그 턴이 끝날 때 풀린다. 상태는 진영별 `SideStatus`(만료 턴 번호 정수)로 두고 해시에 넣는다.
- **P3 화재 (§2.5, BALANCE A2.5·A4.8 임시값):**
  - 화염탄 착탄 = 폭발탄과 같은 착탄 피해 + 화상 지대(착탄 칸 중심 3×3 의 블록)에 불을 붙인다.
  - 불붙은 블록은 **그 배 주인의 턴 끝마다** 블록 피해 10(임시). 나무(소나무·참나무)는 화염탄 사다리의 ‘나무 추가 피해 %’만큼 더 받는다. 철판은 면역이고, 코르크·망사는 나무로 본다.
  - 지속 턴(사다리)이 지나거나 블록이 물에 잠기면 꺼진다. 번짐: 턴 끝마다 불붙은 블록의 이웃 나무 블록 하나에 25%(소나무 50%, 매치 시드 난수, 임시).
  - 불붙은 선실의 해적은 턴 끝마다 피해 10(임시). 화약고·연료통이 터지면 둘레 칸에 불을 붙인다(확률 없이 확정, A3.3 ‘화재 확률 2배’ 문장은 ‘둘레 칸이 불붙는다’로 고치자는 제안).
- **P4 연쇄탄 (§4.8, BALANCE B6 가정):** 해적을 맞혔을 때만 번진다. 같은 배의 아직 안 맞은 해적에게 가까운 순(동률은 낮은 슬롯)으로 사다리 수만큼, 번짐 피해는 원 피해의 50%. 거리 제한 없음, 헤엄 중인 해적 제외.
- **P5 방향 전환 탭 (알바, §2.2·§7.2):** 비행 중 1회. `TAP dir` 의 부호로 진행 방향을 위(+1)·아래(−1)로 45° 돌린다. 그 뒤에도 유도는 계속된다.
- **P6 바람 역전 (알바):** 알바 탄이 적 배(블록·해적)에 맞았을 때만. 다음 상대 턴의 바람 부호를 뒤집는다(세기·폭풍 배율 그대로). 램프의 ‘바람 무시’가 있으면 그쪽이 앞선다.
- **P7 선실 봉쇄 (킹):** 착지 칸에서 가장 가까운 적 선실 1개(동률은 낮은 슬롯), 다음 상대 턴 발사 불가.
- **P8 끌기·이동 불가 (모비):** 선체에 맞았을 때만. 상대 이동 구간·최소 간격 안에서 갈 수 있는 만큼만 끌고 나머지는 버린다. 다음 상대 턴 `MOVE` 불가.
- **P9 궤적 봉쇄·확대 (만타·램프):** sim 에는 ‘다음 턴 궤적 표시 %’ 상태만 둔다(봉쇄 0%, 램프 100%, 겹치면 봉쇄 우선). 앱만 쓰고 AI 는 영향이 없다. 만타의 무작위 피해는 R1a-2.
- **P10 떠 있는 기뢰 (젤리, §2.6):** 바다에 떨어진 x 에 뜬다(선체에 맞으면 지금처럼 부착). 상대 배가 `MOVE` 로 선체 가로 범위가 기뢰 x 를 지나가면 터진다: 흘수선 칸 폭발 피해 + 설치탄 사다리 침수. 놓인 자리가 이미 선체 범위면 바로 부착. 지속 턴이 끝나면 사라진다. 멀 때 1턴 늦는 규칙은 적용하지 않는다.
- 지원탄 분기: 뿜뿜 침수 −15%p(A4.2), 램프 연료 +30·궤적 100%·바람 무시(A4.2), 쿡 아군 쿨다운 −1(치유는 R1a-2).
