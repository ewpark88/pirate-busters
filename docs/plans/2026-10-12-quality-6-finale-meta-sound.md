# 퀄리티 6차: 전투 마무리·턴 리듬, 메타 화면 손맛, 소리·진동, 읽기 쉬움·성능 (A54~A57)

## Context
사용자 요청: "퀄리티 개선 6차, 지금 퀄리티를 높일 곳을 고민해서 계획하라."
1~5차는 전투 화면 안쪽을 다뤘다(타격감, 내구도, 조준, HUD, 상대 턴, 아트). 이번에는 세 갈래로 조사했다.
- 지난 점검(A25·A39·A41·A43, 1~5차 계획)에서 아직 풀리지 않은 항목
- 전투 밖 화면
- 전투 연출의 남은 빈틈

**전투**
- 판의 끝과 턴 사이가 비어 있다.
  - 침몰은 있다. 하지만 '격침!'은 결과 패널 안에서만 뜬다. 설계서 §10.4 '격침'은 가라앉은 뒤 배너를 띄우고 그다음 결과로 가는 순서다.
  - 전멸이나 시간 판정으로 끝나면 곧바로 결과로 넘어간다.
  - 턴이 바뀔 때 멈춤이나 '내 턴' 표시가 없다.
  - `turnStart`·`stormStart` 이벤트를 쓰는 곳이 없다(`battle_cues.dart:220-227`).
- 화재에 연기가 없다(§10.4 '화재').

**메타 화면**
- 공용 키트(`ui/kit/`)는 잘 갖춰져 있다.
- 메타 화면 버튼은 모두 소리가 없다. `Sfx.click` 은 전투에서만 쓴다(§10.3 '버튼 누름').
- 결과 화면의 별은 PopIn 으로만 나온다. 레벨업과 새 해적은 글 한 줄이다(§13.5).
- 선원 슬롯, 설정 토글, 항구 배 누르기에는 눌림 반응이 없다(§13 공통).
- 컷신 바탕이 검은 단색이다(§13 공통에서 금지).

**소리**
- 음악이 하드컷으로 바뀐다(`sound_service.dart:139-153`).
- 턴 전환, 침수, 불, 이동, 바다 환경음 소리가 없다.
- 진동은 착탄, 조준 눈금, 5초 카운트다운에만 있다.

**읽기·성능**
- 방패 효과가 화면에 보이지 않는다(A43 제안 3).
- '상대 턴' 표시가 시간 판정 띠를 덮는다(A43 버그 6).
- 패배 화면 물 띠의 아래 끝이 직선으로 잘린다(A41 버그 6).
- 수리하면 내 HUD 에 회복량이 뜨지 않는다(A41 제안 3).
- `HullWater.paint` 와 `SeaView` 가 매 프레임 Path·Paint 를 새로 만든다.
- 저사양 모드에서 불·폭발 프레임을 줄이지 않는다(§10.4 '저사양').

**사용자 선택 (2026-10-12)**
- 네 묶음을 모두 넣는다.
- 규칙·수치 문제는 제안서만 같이 쓴다(맨 아래 절).
- A35~A37 은 이미 계획돼 있고 다른 세션이 진행 중이라 건드리지 않는다.
- 지옥 번개와 해역 톤은 R3 몫이다.

## 단계·문서
- 계획서 12장 끝에 **A54~A57** 을 추가하고 **ADR-105** 에 함께 기록한다. 규칙 결정은 **A59** 로 둔다(A58 은 화면 전환 잔상 2차)(절대 규칙 11). ADR-104 는 A35·A36 세션이 쓰고 있다.

- 작업 트리는 다른 세션(A35·A36)과 함께 쓴다. 다음은 그 세션 작업과 겹치지 않을 때에만 한다.

  - `git add` 는 내 경로만 한다. 공유 문서는 내 블록만 인덱스에 올린다.
  - 설계서 해시는 그 세션이 커밋한 다음에 갱신한다.

## A54 전투 마무리·턴 리듬 — `app`
- **격침 배너 분리 (§10.4 '격침', 문장 있음):** 침몰이 끝나면(`battle_game.dart:214-235` 의 settled 앞) 월드 위에 '격침!' 배너를 0.9초 띄운 뒤 결과로 넘어간다. 결과 패널 안의 배너(`result_overlay.dart:51-62`)는 뺀다.
- **화재 연기 (§10.4 '화재', 문장 있음):** `fire_view.dart` 에서 연기 입자가 위로 오르게 한다. 저사양에서는 절반만 그린다.
- ✎ **전멸·시간 판정 마무리:**
  - 마지막 해적이 쓰러지면 0.6초 슬로모와 '전멸!' 배너를 띄운다.
  - 시간 판정이면 양쪽 침수 막대를 나란히 비교해 보여 준 뒤 결과로 넘어간다.
- ✎ **턴 전환 비트:**
  - 턴 사이에 0.5초 멈추고, '내 턴!' 배너를 짧게 띄운 뒤 카메라를 옮긴다.
  - '상대 턴' 패널(`battle_hud.dart:244-256`)이 움직이며 나타나고 사라진다.
  - 시뮬은 건드리지 않는다. 턴 시계는 멈춤이 끝난 뒤 시작한다(`StartGate` 방식).
- ✎ **폭풍 진입 배너:** `stormStart` 가 오면 '폭풍 타임!' 배너를 띄우고 화면을 잠깐 어둡게 한다.
- 글자는 ko·en 을 같은 커밋에 넣는다.
- 테스트: 배너 순서(침몰 → 배너 → 결과), 턴 멈춤 동안 시계가 흐르지 않음.
- 골든: 격침 배너, 내 턴 배너.

## A55 메타 화면 손맛 — `app`
- **버튼 소리 (§10.3):** `Pressable`(`ui/kit/kit_motion.dart:127`)과 `PbButton` 에 `Sfx.click` 을 붙인다. 소리 설정을 따른다.
- **눌림 반응 통일 (§13 공통):** 아래를 `Pressable` 로 감싼다.
  - 선원 슬롯·목록 카드(`crew/crew_widgets.dart`)
  - 설정 토글(`port/settings_screen.dart`)
  - 항구 배(`port/port_screen.dart`)
- **결과 화면 별 도장 (§13.5):** 별이 크게 시작해 줄어들며 찍히고, 반짝임과 별마다 소리를 낸다. 결과 화면에서 승리·패배 짧은 소리를 한 번 더 낸다.
- **레벨업·새 해적 축하 (§13.5, §10.5, §13.8):**
  - 레벨업: 빛 배너와 함께 숫자가 올라간다.
  - 새 해적: 등급 카드가 뒤집히며 나오고, 등급색 빛을 낸다.
- **조선소 해금·업그레이드 (§13 공통):** 골드가 세어 내려가고(`CountUp`), 해금된 카드가 튕겨 나오며 반짝인다(`ship_upgrade_sheet.dart`, `tool_card.dart`).
- **선원 빈 슬롯 (§13.7):** 키트 슬롯에 점선과 '+' 로 빈 칸을 보인다. 해적을 놓으면 PopIn 과 소리가 난다.
- **컷신 (§13 공통, §15.4):**
  - 검은 단색 대신 키트 바탕을 쓴다.
  - 대사가 한 자씩 나오고, 누르면 끝까지 한 번에 나온다.
  - 해적이 미끄러져 들어온다.
  - 쪽수 표시를 키트 스타일로 바꾼다(`story/cutscene_screen.dart`).
- **골든 확장:** 결과 화면(패배, 시간 판정, 레벨업, 새 해적), 지도 잠김, 업그레이드 시트, 선원 빈 슬롯.
- **범위 밖** (기능 추가에 가깝다):
  - 지도 모드 탭·해역 넘기기(R3)
  - 조선소 탭 3개(R2)
  - 항구에서 해적을 눌러 상세 보기(R4)

## A57 읽기 쉬움·성능 — `app`
- **방패 표시 (A43 제안 3, §5.4):**
  - 방패가 서 있는 동안 블록 피해 숫자 옆에 방패 아이콘을 붙인다.
  - 마지막 방패 칸이 부서지면 '방패 깨짐!' 이름표를 띄운다.
  - 방패 칸에 금색 테두리를 둘러 장갑 철 블록과 구별한다. 전투 준비 화면의 적 배 그림에도 표시한다.
- **'상대 턴' 겹침 (A43 버그 6):** `FoeAlert` 와 '상대 턴' 패널이 시간 판정 띠를 덮지 않게 자리를 옮긴다.
- **패배 화면 물 띠 (A41 버그 6):** 아래 끝을 물결 모양으로 마감한다.
- **수리 +n% (A41 제안 3):** 수리가 되면 내 선체 게이지 옆에 초록 '+n%' 를 띄운다(`side_status.dart`).
- **성능:**
  - `HullWater` 의 선체 경로는 격자가 바뀔 때만 다시 만들고, Paint·Gradient 는 캐시한다.
  - `sea_view.dart` 에서 매 프레임 생기는 할당을 없앤다.
  - 저사양 모드에서 불·폭발 루프 프레임을 줄인다(§10.4 '저사양').
  - 입자 총량에 전역 상한을 둔다(`fx_layer.dart`).
- 테스트: 방패 이름표 이벤트, 경로 캐시 재사용.
- 골든: 방패 표시, 상대 턴 배치.

## 설계서 문장 제안 (✎, 2026-10-12 사용자가 1~5 모두 승인)
1. **§10.4 '마무리' (새 줄):** 격침이 아닌 승부도 끝을 보여 준다. 전멸이면 마지막 해적이 쓰러질 때 화면을 잠깐 느리게 하고 "전멸!" 배너를 띄운다. 시간 판정이면 양쪽 침수량을 나란히 비교해 보여 준 뒤 결과로 넘어간다.
2. **§13.4 '턴 전환' (새 줄):** 턴이 바뀌면 화면이 0.5초 멈추고 '내 턴!' 또는 '상대 턴' 배너가 짧게 나타났다 사라진 뒤 카메라가 옮겨 간다. 턴 타이머는 그 뒤에 흐른다. 폭풍 타임이 시작되면 '폭풍 타임!' 배너를 띄우고 화면이 잠깐 어두워진다.
3. **§10.3 효과음 목록에 더할 것:** 턴 전환 알림음, 침수(물 차는 소리), 불 타는 소리, 배 이동 물살, 별 찍힘·레벨업.
4. **§10.3 배경음악에 더할 것:** 곡이 바뀔 때는 짧게 겹쳐 넘기고(크로스페이드), 승패 악구와 격침 배너 동안 음악을 줄인다. 전투 중에는 낮은 바다·바람 환경음이 깔린다. 폭풍 타임에는 곡이 서서히 빨라진다.
5. **§10.4 '진동'에 더할 것:** 발사 순간 가벼운 진동, 격침·승리·패배에 긴 진동, 유폭은 짧게 두 번.

## 규칙·수치 결정 (2026-10-12 사용자 승인 → A59)
1. **1-5 적이 맞히지 못함 (A43 버그 5):** `tools/sim_runner` 로 1-5 편성에서 적의 명중률을 잰다. 원인을 확정한 뒤 다이얼이나 적 덱 수정안을 따로 제안한다(BALANCE.md A5.2). 승인 전에는 구현하지 않는다.
2. **12턴 별 (A43 제안 6):** 내 턴 수로 세고, 12번 안에 이기면 별을 준다(§6.1, BALANCE.md A6.1). 미션 `turns_within` 도 내 턴 수로 센다.
3. **튜토리얼 3 남은 물 (A43 제안 7):** 튜토리얼 3 에만 내 배에 펌프 하나를 단다(§13.1).
4. **방패와 선실 피해 (A43 제안 5):** 규칙은 그대로 둔다. 1-5 적 배 설계도에서 방패 철판이 선실 앞을 가리게 한다.
5. **공격 해적이 없을 때 (A25 제안 2):** KO 되지 않은 해적이 모두 보급 계열이면 전멸로 보고 진다(§2.4).

## 검증
- **단계마다:**
  - 위젯·단위 테스트를 쓴다. 테스트 이름은 한국어 문장으로 한다.
  - 바뀐 화면의 골든을 ko·en 으로 찍는다.
  - `bash tool/verify.sh` 를 통과시키고 `rules-reviewer` 검토를 받는다.
  - `pb_sim` 은 바꾸지 않으므로 리플레이 해시가 그대로여야 한다.
- **전후 캡처:** 격침, 전멸, 내 턴, 결과 별, 레벨업, 방패 장면을 찍어 `docs/quality/` 에 둔다.
- **끝나면:**
  - PROGRESS·CHANGELOG `[Unreleased]`·STATUS 를 고친다.
  - 브랜치 push → main 병합 → main push 까지 한다(ADR-098).
  - 사람 확인(실기기 소리 크기, 진동 세기, 저사양 프레임)은 보고에 남긴다.
