# 설계서 재대조 2차 반영 — 이 세션 몫 (보스 난이도·전투 중 언어·문서 정합)

## Context

전체 검토(Phase 0 ~ A8)에서 설계서·계획서와 어긋난 곳을 찾았고, 사용자가 “다중투하 분배 / 보스 난이도 / 전투 중 언어 / 설계서·BALANCE 문구 수정과 A9 신설”을 진행하라고 했다(화약고 폭발 시점은 보류했으나 다른 세션이 설계서 문구대로 ‘맞으면’ 으로 고치는 중).

같은 폴더·브랜치(`feat/M6-balance`)를 쓰는 다른 세션이 **검토 지적 1~4(망사·화약고·다중투하·연패)와 ADR-050, 계획서 12장 A9 신설, 설계서 §4.8, BALANCE A3.2·A4.3·A4.8, pirates.json, pb_sim·pb_ai** 를 맡았다(30분 요청). 그래서 이 세션은 겹치지 않는 아래 몫만 한다. 다른 세션 커밋 알림이 온 뒤에 시작하고, 그쪽 파일은 건드리지 않는다.

가정: ‘진행해’ = 설계서를 따르는 쪽으로 결정 — 보스는 §6.1 대로 **쉬움**, 전투 중 언어 변경은 §14.1 대로 **불가**, 설계서·BALANCE 문구는 **사용자 허락으로 에이전트가 직접 수정**(ADR-025 선례)하고 `/doc-sync` 로 계획서 해시를 맞춘다.
