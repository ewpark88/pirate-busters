# 퀄리티 4차: 전투 타격감 — 피해 비례 피드백·파괴 물리·소리 겹침·해적 반응·발사 (A32)

> 색인: docs/plans/README.md

## Context
사용자 지적: 1차 진단(docs/quality/2026-10-02-gap-analysis.md)의 기준인 Castle Busters 와 비교하면 타격감·전투 손맛이 아직 많이 떨어진다. 재미를 느끼고 이탈하지 않을 수준까지 올려야 한다.

A14·A15·A17·A20 에서 장치는 대부분 넣었다. 남은 문제는 **세기·비례·겹침**이다. 2026-10-06 코드 조사 결과는 다음과 같다.
- **큰 한 방과 작은 한 방이 똑같다.**
  - 히트스톱은 0.07초 고정이고, 펀치 줌은 6% 고정에 선형으로 풀린다.
  - 흔들림은 계열별 고정값(3~12px)이고, 등급 배율은 최대 1.2다.
  - 폭발은 탄 반경과 상관없이 늘 반경 1로 그린다(`fx_layer.dart:98`).
  - 피해 숫자는 18pt 노랑 하나뿐이다.
- **부서짐이 "사건"이 되지 않는다.**
  - 맞은 칸은 바로 사라지고 판자 파편 4개만 튄다.
  - 붕괴는 칸마다 따로 직선으로 떨어진다. 덩어리·연쇄 지연·우지끈 소리·흔들림이 없다(`collapse_fx.dart`).
- **소리가 얇다.**
  - 착탄음이 발사음 `cannon` 을 그대로 다시 쓴다.
  - 비행음·해적 피격음·추락 첨벙·붕괴음·피해 단계별 소리가 없다.
- **해적이 반응하지 않는다.**
  - `pirateFell`·`pirateDown` 을 무시한다(`battle_cues.dart:198`).
  - 피격 클립의 flash·shake 이벤트를 쓰지 않는다(`anim_data.dart:60` 은 파싱만 한다).
- **발사가 밋밋하다.**
  - 포구 화염·연기가 없다.
  - 던지는 동작(`spawn` 1.4초)이 탄보다 약 1.4초 늦게 나올 수 있다. 버그로 의심되며 확인이 필요하다.
  - 당길 때 햅틱이 없다.
- **장르 기준 수치(웹 조사):**
  - 히트스톱: 피해에 비례하고 50~160ms
  - 흔들림: trauma² 방식(Eiserloh)
  - 흰 번쩍임: 0.1초
  - 햅틱: TICK·CLICK·THUD
  - 결정타: 슬로모
  - 효과 양: "없음"과 "과다" 모두 플레이 시간이 줄었다(Kao 2020). 그래서 **중간~높음**으로 맞춘다.

사용자 결정 (2026-10-06):
- A26 과 나란히 바로 한다. `ship_view.dart` 가 겹치는 부분만 A26 머지 뒤에 한다.
- A30 감정 연출은 돛대를 뺀 나머지를 A32 에 합친다. 돛대 부러짐 트리거만 A30 에 남긴다(A27 뒤).
- 세기는 중간~높음으로 하고, 설정에 '화면 흔들림 줄이기'를 둔다.

모두 **렌더 전용**이다(절대 규칙 3). `pb_sim` 판정·리플레이 해시는 바꾸지 않는다. 밸런스 수치가 아니어서 BALANCE.md 는 바꾸지 않는다. 연출 상수는 앱 코드에 둔다.

## 0단계 — 문서 (먼저, 사용자 승인)
설계서는 직접 고치지 않는다.
1. 수정안을 `docs/proposals/2026-10-06-quality-4-design-diff.md` 에 diff 로 쓰고 승인을 받는다.
   - §10.4 명중: "0.07초 멈춤" → "피해에 비례해 0.05~0.16초 멈춤(큰 한 방은 맞은 배가 떨리며 멈춘다)". 맞은 블록·해적은 흰 번쩍임 0.1초. 폭발 크기는 탄의 폭발 반경을 따른다.
   - §10.4 카메라: 흔들림·당기는 줌은 한 방의 크기(피해·부순 칸·해적 피해)에 비례하고 상한을 둔다. 설정 '화면 흔들림 줄이기'를 따른다.
   - §10.4 파괴(새 문장): 부서진 칸은 재질별 조각(나무 판자·철판)으로 튀어 돌며 떨어진다.
   - §10.4 붕괴: 끊긴 덩어리는 한 덩어리로 기울어 떨어진다. 연쇄되는 덩어리는 조금씩 늦게 떨어진다. 떨어질 때 우지끈 소리, 물에 닿을 때 흔들림이 난다.
   - §10.4 피해 숫자: 피해 단계별로 크기·색이 다르다(작음·큼·치명). 큰 숫자는 튀며 흔들린다.
   - §10.4 해적 반응(새 문장): 맞으면 뒤로 밀리며 번쩍인다. 바다로 떨어지면 포물선을 그리며 날아가 물보라와 첨벙 소리를 낸다. 쓰러지면 KO 별이 돈다.
   - §10.4 발사(새 문장): 포구 화염·연기, 던지는 동작과 탄 출발을 맞춘다. 당길 때 힘 눈금마다 가벼운 진동, 최대 힘에서 딸깍.
   - §10.4 물 착탄: 물기둥과 물방울.
   - §10.4 감정 연출: 그대로 둔다. 돛대 붕괴는 A30 에 남는다.
   - §10.3 효과음 목록: 비행음, 해적 피격·추락 첨벙·KO, 붕괴 우지끈, 피해 단계별 착탄 겹침(쾅 + 재질 부서짐 + 잔향)을 더한다.
   - §10.4 햅틱(새 문장): 한 방 크기 3단계(가벼움·중간·묵직). 한 착탄에 한 번만 울린다.
   - §13 설정: '화면 흔들림 줄이기' 토글.
2. 승인되면 `/doc-sync` 를 한다.
   - 계획서 12장 끝에 **A32 전투 타격감 4차** 를 넣는다.
   - A30 은 '돛대 부러짐 슬로모션·문구'만 남기고, 나머지는 A32 로 옮겼다고 적는다.
   - 해시·날짜를 갱신한다.

## A32 작업 (`feat/A32-hit-feel`, 묶음마다 커밋)

### 32a 한 방 크기와 비례 피드백 — `app/lib/game/`
- 새 파일 `game/view/hit_weight.dart` 를 만든다.
  - 착탄 이벤트 묶음(피해 합, 부순 칸 수, 해적 피해, 치명, 유폭, 격침)에서 렌더 전용 `HitWeight`(0~1000 정수 등급 + 가벼움·중간·묵직 3단계)를 계산한다.
  - 상수표를 한 곳에 모은다.
- `battle_cues.dart`·`impact_accent.dart`: 히트스톱 길이를 등급에 따라 50~160ms 로 한다. 묵직은 멈춘 동안 맞은 배만 떨린다(카메라는 멈춤).
- `shake.dart`: trauma 방식(trauma² 진폭, 이벤트마다 더하고 감쇠)으로 바꾼다. 작은 회전(최대 약 1.5°)을 더한다. 기존 사인 노이즈는 다시 쓴다. 설정 '줄이기'는 ×0.35.
- `camera_director.dart` 펀치 줌: 4~12% 비례, 빠르게 당기고 ease-out 으로 복귀(약 0.3초).
- `fx_layer.dart`:
  - `hit` 은 탄의 폭발 반경을 `explosion(at, radius)` 로 넘긴다.
  - 묵직이면 충격파 고리(기존 shockwave 스프라이트)를 더한다.
  - 햅틱은 3단계로 하고 한 번만 울린다(곡사 계열 두 번 울림을 고친다).
- `fx_text.dart` 피해 숫자 3단계:
  - 작음: 18pt 흰색
  - 큼: 26pt 주황, 튐 + 흔들림
  - 치명: 30pt 빨강 + 테두리
  - 끝에 페이드아웃을 넣는다.
- 맞은 블록 흰 번쩍임 0.1초: `damage_layer` 위에 얹는다. 해적 번쩍임은 32d 에서 한다.
- 테스트: `HitWeight` 경계값, 히트스톱·줌·흔들림 단조 증가와 상한, 같은 입력이면 같은 출력, 줄이기 설정, 한 착탄에 햅틱 1회. 기존 `battle_fx_test`·`shake_motion_test` 를 갱신한다.

### 32b 파괴 물리 — `collapse_fx.dart`, `fx_layer.dart`, 새 `game/view/shard_fx.dart`
- 부서진 칸: 타일 그림을 재질별 2~4조각(나무는 판자 결 방향, 철판은 휘어진 조각)으로 잘라 속도·회전을 주고 중력으로 떨어뜨린다. 물에 닿으면 작은 물보라를 낸다.
  - 모양과 방향은 (칸 x, y, 착탄 틱) 해시로 정한다. 리플레이에서도 같다.
  - 저사양은 조각 수를 절반으로 한다.
- 붕괴: 끊긴 칸을 연결 덩어리로 묶어 한 몸으로 기울어 떨어뜨린다(회전 중심 = 덩어리 지지 끊긴 쪽).
  - 덩어리마다 0.08초씩 늦게 떨어뜨린다.
  - 떨어지기 시작할 때 우지끈 소리, 물에 닿을 때 흔들림(중간) + 큰 물보라.
- 테스트: 조각 수·결정성, 덩어리 묶기(연결 성분), 연쇄 지연 순서, 저사양 절반.

### 32c 소리 겹침 — `app/lib/audio/`, `app/assets/audio/`, `docs/ASSETS.md`
- 새 CC0 음원(Kenney Impact/Sci-fi·OpenGameArt 등)을 고르고 출처 페이지에서 CC0 를 확인한다.
  - 착탄 쾅(대·중·소)
  - 나무 부서짐·철판 찌그러짐 변형
  - 붕괴 우지끈
  - 비행 휘파람(곡사 탄이 내려올 때)
  - 해적 피격 "윽"·첨벙·KO
  - 물 착탄 물기둥
  - `Sfx` 를 늘리고 `sound_library.dart` 변형 규칙을 따른다.
- `battle_cues.dart`: 착탄은 `HitWeight` 단계별 쾅 + 재질 부서짐 + (묵직이면) 잔향을 겹친다. `cannon` 재사용은 없앤다. 같은 틱에 같은 소리가 겹치면 1개로 하고 볼륨 상한을 둔다.
- 음원이 없으면 합성음으로 대신한다(기존 규칙).
- 테스트: 단계별 소리 선택, 동시 재생 상한, 대체 동작(`sound_library_test`·`audio_test` 확장).

### 32d 해적 반응·발사 — `ship_view.dart`, `character_rig.dart`, `battle_cues.dart` (A26 머지 뒤)
- 던지는 동작 타이밍 버그를 먼저 확인한다. 실제 늦게 나오면, 공격 클립을 `spawn` 이벤트 직전부터 재생하거나 탄 출발 연출을 클립 `spawn` 에 맞춘다. 판정 틱은 그대로 둔다.
- 포구 화염·연기 퍼프: 기존 `fx/impact/flash` + smoke 파티클을 쓴다. 발사 반동은 그대로 둔다.
- 해적 피격:
  - 피격 클립 `events` 의 flash·shake 를 실제로 쓴다(`AnimClip.events`).
  - 맞은 방향으로 넉백, 흰 번쩍임 0.1초.
- `pirateFell`: 포물선으로 날아가 수면 물보라 + 첨벙 → 기존 swim 으로 넘어간다.
- `pirateDown`: KO 별 고리 + KO 소리 → 페이드.
- 조준: 힘 링 눈금마다 TICK 햅틱, 100% 에서 CLICK 햅틱(`aim_sling.dart`).
- 물 착탄: `water_spike` + 물방울 파티클 + 가벼운 흔들림.
- 테스트: 클립 이벤트 소비, 추락 경로가 수면에서 끝남, KO 연출 트리거, 조준 햅틱 횟수.

### 32e 감정 연출 (A30 에서 옮김) — `battle_game.dart`, 새 `game/view/slowmo.dart`, `fx_text.dart`
- 슬로모션: 격침·선실 직격 때 화면 재생만 약 0.6초 동안 0.3배로 한다. 시뮬 틱은 그대로다(설계서 §10.4). 히트스톱과 같은 시계 경로를 쓴다.
- 강조 문구:
  - 큰 피해(`HitWeight` 묵직): "콰광!"
  - 같은 턴 두 발 명중: "연속 명중!"
  - 선실 직격: "선실 직격!"
  - 큰 외곽선 글자로 튕기며 등장시키고, 한 턴 최대 1개만 띄운다.
- 추락·KO 전용 소리는 32c·32d 에서 한다.
- 설정 '화면 흔들림 줄이기' 토글: `settings_store`, 설정 화면.
- 글자: `app_ko.arb`·`app_en.arb` 같은 커밋(절대 규칙 10).
- 저사양: 슬로모 길이 절반, 문구 크기 축소(§10.4 저사양).
- 테스트: 트리거·빈도 제한, 같은 입력이면 같은 연출, 리플레이 해시 불변, 설정 저장. 전투 골든을 다시 만든다.

### 32f 전후 비교 — `docs/quality/2026-10-xx-hit-feel.md`
- 웹 릴리스 빌드를 헤드리스 크롬에서 1차 진단과 같은 장면(내 착탄·상대 착탄·붕괴·격침)으로 연속 캡처해 A32 전과 후를 나란히 놓는다.
- 각 장면에 히트스톱·흔들림·줌·숫자·소리 목록을 적는다.
- 중간 캡처는 저장소 밖 임시 폴더에서 만들고, 남길 것만 `docs/quality/img/` 에 넣는다.
- 실기기 손맛 확인은 이월 항목으로 남긴다.
