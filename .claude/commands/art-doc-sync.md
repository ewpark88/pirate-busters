# 설계서 아트 동기화 (사용자 승인)

**이 작업은 사용자가 직접 승인한 설계서 수정이다.** CLAUDE.md 의 “설계서는 직접 고치지 않는다” 규칙의 예외로, 아래에 적힌 절만 고친다.

- `docs/BALANCE.md` 와 밸런스 수치는 건드리지 않는다. 아래 내용에는 수치 변경이 없다.
- 아래 목록에 없는 절을 고치고 싶으면, 고치지 말고 끝에 제안으로만 보고한다.
- 문체는 설계서의 기존 문체(평서문, 짧은 문장, 표·목록)를 따른다.
- 절 번호를 새로 만들면 목차 성격의 다른 참조(예: “10.2”)가 깨지지 않는지 확인한다.

배경: 아트 에셋 패키지 v0.21(`art/`)과 ‘해적 캐릭터 단계별 개선’ 페이지 22단계까지의 디자인이 지금 설계서 10장·13장·4.3 의 문구보다 앞서 있다. 코드(`app/assets/game/pirates.json`, `ammo.json`)는 이미 아래 키를 쓴다.

## 1. §10 머리말: 아트 스타일 규칙 교체

지금 문장 “스타일 규칙: 외곽선은 진갈색 한 가지(바깥 5, 안쪽 2~3), … 오른쪽 가장자리에 푸른 빛. 얼굴은 큰 눈·작은 입·볼터치로 단순하게.” 를 아래 내용으로 바꾼다. 첫 문장(플랫 2D 벡터 + 캐주얼 종족, SVG, 0원)과 마지막 문장(단계별 개선 기록 페이지)은 그대로 둔다.

- **톤:** 귀여움과 사나움의 중간. 약 2.5등신, 머리가 크고 몸은 짧다. 아이도 어른도 즐길 수 있는 정도로, 이를 드러내거나 찌푸린 얼굴은 쓰지 않는다.
- **외곽선:** 거의 검정에 가까운 남색 한 가지(#14161c). 본체 4~4.5, 안쪽 선 2~3.
- **빛:** 해 질 녘 역광이 기준이다. 뒤쪽 위에서 오는 빛이 몸 왼쪽 가장자리에 주황 림라이트(#ffb36b)를 만들고, 오른쪽은 짙은 그림자 한 단으로 덮는다. 캠페인 모드 톤(10.2)은 이 그림에 조명·팔레트 값만 바꿔 적용한다.
- **얼굴:** 흰자 + 색 홍채 + 동공 + 하이라이트 점. 윗눈꺼풀이 눈의 약 20%를 덮어 차분한 인상을 준다. 볼터치는 쓰지 않는다.
- **장비:** 가죽·금속 소품, 금 장식(#c9962e)으로 해적다움을 낸다.
- **팀 색:** 우리 팀 파랑(#2f62c4 / 밝은 쪽 #6f97e6), 상대 팀 빨강(#b3302b / #e06a5a).

## 2. §10.1 해적 파츠 시스템

1. 표의 **무기·투사체** 행을 바꾼다.
   - 내용: “해적마다 고유 무기 1개(탄종 4.8 과 짝). 발사체 스프라이트, 다중투하용 소형 폭탄, 강습·지원 효과 아이콘”
   - 수량: “발사체 35 + 소형 폭탄 1 + 효과 아이콘 10”
2. 표에 **탄종 아이콘** 행을 추가한다.
   - 내용: “탄종 13개의 둥근 배지 아이콘. 카드 칩·해적보감에 쓴다(4.8, 13.4, 13.9)”
   - 수량: “13”
3. “게임 크기(약 80px)에서 검정 실루엣만으로…” 문장의 크기 부분을 바꾼다: “전투 화면 크기(키 약 0.9칸, 블록 32px 기준 1x 약 22×29px)에서 검정 실루엣만으로 누구인지 알아야 한다. 배는 성처럼 크게, 해적은 선실 한 칸 안에 들어가는 크기로 그리고, 조준 때 카메라가 그 해적으로 줌인한다(2.2). 무기는 몸에 비해 크게 그리고, 공격 동작 때는 칸 밖으로 나가도 된다.” (ADR-057. 아트 패키지의 ‘키 약 1.5칸·선실 3×2칸’ 은 따르지 않는다)
4. 아래 목록을 추가한다(애니메이션 상태 목록 바로 앞).
   - **부위 리그:** 그림자·뒤(꼬리·망토)·몸·머리·눈·팔·뒤팔·들고 있는 무기를 따로 나눈 SVG 다. 캔버스는 240×324, 기준점은 발(120, 315)이다. 동작은 부위별 키프레임 데이터(`anims.json`)로 재생한다.
   - **전투 외곽선:** 전투 크기에서는 실루엣을 바깥으로 한 겹 넓혀(1x 약 1px) 바다·배 위에서도 윤곽이 묻히지 않게 한다. 얼굴 안쪽 선은 굵히지 않는다.
   - **고유 무기:** 같은 계열이라도 해적마다 다른 무기를 쓴다(예: 투척 = 폭탄·불별·쌍폭탄·성게·용암 바위). 날아가는 길은 탄종 규칙을 따르고, 그림·고유 꼬리(불꽃·용암·전기·거품·물·바람·연기)·명중 이름표만 해적마다 다르다. 개수(조각·발수·투하)는 사다리 값을 따른다(4.8).

